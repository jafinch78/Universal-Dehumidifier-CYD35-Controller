# Hardware starter package

This folder is the first low-voltage hardware definition for the project. It intentionally stops at the relay/contactor **coil interface** and does not claim to be a universal mains power board.

- `BOM.csv` — proposed V0.1 prototype bill of materials
- `LOW_VOLTAGE_WIRING.md` — connection-level schematic and wiring notes

All are unreviewed design artifacts and require critical schematic/BOM review before assembly.
